# reef-kh

珊瑚缸 KH 數據分析練習。使用 HTML、CSS 與原生 JavaScript，不使用框架。

## 缸子資料

以下兩項之後計算「每日 KH 消耗量」與「建議添加量」時會用到，請填入實際數值。

| 項目 | 數值 | 說明 |
|---|---|---|
| 缸子實際水量 | ＿＿＿ 公升 | 主缸加底缸的實際水量，需扣除岩石與底砂占掉的體積 |
| 添加劑濃度 | ＿＿＿ | 例如：每 ＿ mL 可讓 100 公升的水提升 ＿ dKH（請依產品標示填寫） |

- 添加劑品牌／品名：＿＿＿
- KH 測試方式：＿＿＿

## 檔案結構

```
reef-kh/
├── index.html            頁面骨架
├── css/style.css         樣式
├── js/app.js             主程式：統計卡片、表格，目標 KH 設定在這裡
├── js/data.js            讀取 JSON、整理每日資料、統計與格式化
├── js/chart.js           用 SVG 畫 KH 趨勢圖與添加量圖
└── data/kh-records.json  KH 紀錄（2026-08-25 起的實際測量值）
```

## 如何執行

不能直接雙擊 `index.html`，瀏覽器會擋下讀取 JSON 的動作，必須透過本機伺服器開啟。

1. 用 VS Code 開啟這個資料夾
2. 安裝擴充套件 Live Server
3. 在 `index.html` 上按右鍵，選「Open with Live Server」

## 資料格式

`data/kh-records.json` 是一個陣列，每一筆紀錄的欄位如下：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `date` | 字串 | 日期，格式 `YYYY-MM-DD` |
| `time` | 字串 | 測量時間，格式 `HH:MM` |
| `kh` | 數字 | KH 值，單位 dKH |
| `dose_ml` | 數字 | 當日添加量，單位 mL |
| `type` | 字串 | `"tank"` 魚缸水，`"standard"` 標準液驗證。省略時視為魚缸水 |
| `exclude` | 布林 | `true` 表示異常或可疑讀值，不納入統計與折線，圖上以 × 標示。省略時視為 `false` |
| `note` | 字串 | 備註，沒有就填 `""` |

`time` 與 `dose_ml` 不確定時分別填 `""` 與 `null`。

## 統計規則

- 目標 KH 為 8.3 dKH，設定在 `js/app.js` 的 `TARGET_KH`。
- 標準液讀值與 `exclude` 為 `true` 的讀值不納入統計，但仍會顯示在表格中。
- 同一天有多筆有效讀值時，取平均作為當天的 KH。

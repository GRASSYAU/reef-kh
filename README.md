# reef-kh

珊瑚缸 KH 數據分析練習。使用 HTML、CSS 與原生 JavaScript，不使用框架。

## 缸子資料

計算「每日 KH 消耗量」與「建議添加量」時使用，實際數值設定在 `js/config.js`，有變動時請兩邊一起更新。

| 項目 | 數值 | 說明 |
|---|---|---|
| 缸子實際水量 | 47 公升 | 整套系統的實際水量，採保守估算 |
| 添加劑濃度 | 每 100 L 添加 7 mL 原液，提高 0.18 dKH | 產品標示 |
| 稀釋比例 | 原液 170 mL＋RO/DI 580 mL，共 750 mL | 滴定機使用的是稀釋液 |
| 換算結果 | 1 mL 稀釋液約提高 0.0124 dKH | 以 47 L 計算的理論值 |
| 滴定機校準 | 2026-11-12 校準為每 1 mL 實出 1 mL | 校準前實測 0.8 至 0.9 mL，計算時以 85% 換算 |

- 添加劑品牌／品名：P. Ocean KH 添加液
- 目標 KH：8.3 dKH
- KH 測試方式：＿＿＿

## 檔案結構

```
reef-kh/

├── css/style.css         樣式
├── js/app.js             主程式：統計卡片、表單、表格、分析結果的顯示
├── js/config.js          設定：目標 KH、水量、添加劑濃度與稀釋比例
├── js/analysis.js        估算每日 KH 消耗量
├── js/data.js            讀取 JSON、整理每日資料、統計與格式化

```

## 如何執行

不能直接雙擊 `index.html`，瀏覽器會擋下讀取 JSON 的動作，必須透過本機伺服器開啟。

1. 用 VS Code 開啟這個資料夾
2. 安裝擴充套件 Live Server
3. 在 `index.html` 上按右鍵，選「Open with Live Server」

## 新增、編輯與刪除紀錄

1. 新增：在頁面上的表單輸入數值，按「新增」。
2. 編輯：在表格該列按「編輯」，內容會帶入表單，修改後按「儲存修改」。
3. 刪除：在表格該列按「刪除」。

這些變更會先暫存在瀏覽器的 localStorage，還沒有寫入檔案。要永久保存：

1. 按「匯出 JSON」下載 `kh-records.json`，用它取代 `data/kh-records.json`。
2. 在 VS Code 的「原始檔控制」提交並同步。
3. 重新整理頁面，已寫入檔案的變更會自動從瀏覽器暫存中移除。

暫存的變更只存在同一台電腦的同一個瀏覽器，清除瀏覽資料就會消失，請定期匯出。
寫入檔案前，可按「捨棄未寫入的變更」讓畫面回到檔案裡的內容。

## 資料格式

`data/kh-records.json` 是一個陣列，每一筆紀錄的欄位如下：

| 欄位 | 型別 | 說明 |
|---|---|---|
| `date` | 字串 | 日期，格式 `YYYY-MM-DD` |
| `time` | 字串 | 測量時間，格式 `HH:MM` |
| `kh` | 數字 | KH 值，單位 dKH |
| `dose_ml` | 數字 | 當日添加量，單位 mL |
| `type` | 字串 | `"tank"` 魚缸水，`"standard"` 標準液驗證。省略時視為魚缸水 |
| `exclude` | 布林 | `true` 表示異常或可疑讀值，不納入統計與折線，圖上以 × 標示。省略時視為 `false` |
| `note` | 字串 | 備註，沒有就填 `""` |

`time` 與 `dose_ml` 不確定時分別填 `""` 與 `null`。

## 統計規則

- 目標 KH 為 8.3 dKH，設定在 `js/config.js` 的 `TARGET_KH`。
- 標準液讀值與 `exclude` 為 `true` 的讀值不納入統計，但仍會顯示在表格中。
- 同一天有多筆有效讀值時，取平均作為當天的 KH。

## 消耗量的算法

- KH 每天的變化等於「添加劑補充的量」減去「缸子消耗的量」。
- 把每一天的 KH 減掉累計補充量，再用最小平方法求出下降的斜率，就是每日淨消耗量。
- 淨消耗量已包含例行換水帶來的補充，因此「維持 KH 不變所需添加量」的前提是換水習慣不變。
- 2026-11-12 校準滴定機之前，紀錄中的添加量是設定值，計算時乘上 85% 換算成實際出水量，並把 80% 至 90% 的差異算進估計範圍。資料檔保留原本的設定值。
- 補充量依產品標示換算，是理論值；結果是估算，僅供調整添加量時參考。

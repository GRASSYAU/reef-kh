    消耗量與建議添加量

    計算依據與限制
      • 添加劑的效果依產品標示換算，是理論值，實際效果可能有落差。
      • 建議添加量是校準後滴定機的實際毫升數，可以直接對應現在的設定值。
      • 單次測量有誤差，區間越短結果越不穩定；估計範圍越寬，代表越不可靠。
      • 區間內如果換過稀釋比例或添加劑，或滴定機出水量再次偏移，實際添加量與紀錄不符，結果會失準。
      • KH 升高後，珊瑚的消耗量可能跟著改變，到達目標後請重新觀察。
      • 這裡的數字是估算，調整添加量時建議小幅調整，並持續測量確認。

      同步與匯出

      GitHub 同步

      設定權杖（token，一組代表你身分的密碼）之後，紀錄會直接存進 GitHub 上的存放庫，不需要匯出檔案，手機也能用。

      如何產生權杖
      1. 用瀏覽器開啟 github.com/settings/personal-access-tokens/new。手機版的 GitHub 選單裡找不到這個頁面，請直接用這個網址。
      2. 「Token name」（名稱）自己取，例如 reef-kh-phone；「Expiration」（有效期限）選一個期限。
      3. 「Repository access」（可存取的存放庫）選「Only select repositories」，只勾選 reef-kh。
      4. 「Permissions」（權限）按「＋」，加入「Contents」（內容），再把它改成「Read and write」（讀取與寫入）。
      5. 按「Generate token」。畫面上 github_pat_ 開頭的那串文字只會顯示這一次，請立刻複製，不要重新整理。
      6. 回到這裡，貼到上面的欄位，按「儲存並測試」。
      • 權杖只存在這台裝置的瀏覽器，不會寫進專案，也只會傳給 GitHub。每台裝置要各設定一次；加入主畫面後，要在主畫面開啟的畫面裡設定。
      • 這個權杖可以修改 reef-kh 存放庫的內容，請不要提供給別人。裝置遺失或不再使用時，到 GitHub 把它刪除。
      • 權杖到期後同步會失敗，回到同一個頁面按「Regenerate token」重新產生再貼上即可。

      匯出

      不用 GitHub 同步時，如何把變更寫回專案
      1. 按「匯出 JSON」，下載 kh-records.json。
      2. 用下載的檔案取代專案裡的 data/kh-records.json。
      3. 在 VS Code 的「原始檔控制」提交並同步。
      4. 重新整理這個頁面，已寫入資料檔的變更會自動從瀏覽器暫存中移除。

      加入手機主畫面

      iPhone：用 Safari 開啟這個網頁，按分享按鈕，選「加入主畫面」。Android：用 Chrome 開啟，按右上角選單，選「加到主畫面」。之後從主畫面的圖示開啟，就像一般的 App。

      重新載入

      從主畫面開啟時沒有重新整理的按鈕。程式更新後畫面沒有變，或想重新讀取資料時，按這裡。還沒同步的變更不會消失。

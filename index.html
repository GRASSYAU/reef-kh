GitHub 同步設定（手機使用時需要）

設定權杖（token，一組代表你身分的密碼）之後，按「同步到 GitHub」就能把變更直接存進存放庫，不需要匯出檔案，手機也能用。

如何產生權杖（在 GitHub 網站上操作，介面是英文）：

  1. 點右上角的大頭貼，選「Settings」（設定）。
  2. 左側選單最下方選「Developer settings」（開發人員設定）。
  3. 選「Personal access tokens」（個人存取權杖）→「Fine-grained tokens」（細部權限權杖）→「Generate new token」（產生新權杖）。
  4. 「Repository access」（可存取的存放庫）選「Only select repositories」，只勾選 reef-kh。
  5. 「Permissions」（權限）裡的「Contents」（內容）設為「Read and write」（讀取與寫入）。
  6. 按「Generate token」，複製 github_pat_ 開頭的那串文字，貼到上面的欄位。
  • 權杖只存在這台裝置的瀏覽器，不會寫進專案，也只會傳給 GitHub。每台裝置要各設定一次。
  • 這個權杖可以修改 reef-kh 存放庫的內容，請不要提供給別人。裝置遺失或不再使用時，到同一個頁面把它刪除。
  • 權杖到期後同步會失敗，重新產生一個再貼上即可。
不用 GitHub 同步時，如何把變更寫回專案
  1. 按「匯出 JSON」，下載 kh-records.json。
  2. 用下載的檔案取代專案裡的 data/kh-records.json。
  3. 在 VS Code 的「原始檔控制」提交並同步。
  4. 重新整理這個頁面，已寫入資料檔的變更會自動從瀏覽器暫存中移除。

KH 趨勢 (dKH)

    每日添加量 (mL)

    消耗量與建議添加量

    計算依據與限制
      • 添加劑的效果依產品標示換算，是理論值，實際效果可能有落差。
      • 建議添加量是校準後滴定機的實際毫升數，可以直接對應現在的設定值。
      • 單次測量有誤差，區間越短結果越不穩定；估計範圍越寬，代表越不可靠。
      • 區間內如果換過稀釋比例或添加劑，或滴定機出水量再次偏移，實際添加量與紀錄不符，結果會失準。
      • KH 升高後，珊瑚的消耗量可能跟著改變，到達目標後請重新觀察。
      • 這裡的數字是估算，調整添加量時建議小幅調整，並持續測量確認。
